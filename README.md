Gosto de entender **como um sistema se comporta sob pressão**: medir com método, achar o gargalo, separar o que é fato do que é hipótese e explicar o resultado de um jeito que qualquer pessoa da equipe consiga acompanhar.

Além da faculdade, estudo por conta própria dados , redes, Linux, cibersegurança e inteligência artificial. No meu trabalho de conclusão de curso, fiquei responsável por **infraestrutura, segurança/LGPD e testes de carga** de uma plataforma de gestão de frotas.

## 🚀 Projeto em destaque: FleetSync (TCC)

Plataforma de gestão de frotas com app móvel, painel web e backend, desenvolvida em equipe de quatro pessoas.

**O que eu fiz:**
- 📈 **Testes de carga** com k6 e Kafka (xk6-kafka): leitura de perfil e frota, sincronização de aparelhos em rajada e telemetria GPS em fluxo contínuo.
- 🔎 **Análise de desempenho**: relatório com gargalos, limites encontrados e ações recomendadas, medido em dois ambientes (nuvem e local).
- 🔒 **Segurança e LGPD**: controles de segurança, Row Level Security no banco, trilha de auditoria e justificativa de finalidade e base legal para dados de localização.
- ⚙️ **Integração contínua** com GitHub Actions.

**Resultados medidos (ambiente local):**

| Cenário | Resultado |
|---|---|
| Leitura, 200 usuários | p95 de 4,30 ms, sem erros |
| Sincronização, 200 aparelhos em rajada | p95 de 0,91 s |
| Telemetria Kafka, 2.000 mensagens/s | sem perda e sem duplicidade |
| Ponto de ruptura | entre 1.200 e 1.400 usuários simultâneos |

📂 Repositório do backend: [`tcc-backend-sistema-frotas`](https://github.com/gabrielvbrito/tcc-backend-sistema-frotas)
